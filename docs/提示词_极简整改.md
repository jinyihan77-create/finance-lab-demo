# 工作台极简整改提示词

## 背景
现有「银行 AI 智能体」工作台（workspace.html）功能完整但操作复杂：8 张一键卡 + 6 张场景卡 + 示例芯片 + 打字入口堆在同一页；任务结果与待确认分散在不同标签页，用户点完卡片后还要再切页才能确认。目标是让"完全不懂金融的普通用户"三步内完成一件事。

## 产品定位
不是功能展厅，是"点一下 → 出结果 → 点头/摇头"的极简任务机器。所有解释性内容收进折叠区或说明文档，界面只留行动。

## 具体整改（按此执行，不得自由发挥新增功能）

1. **主界面只留 4 张大卡**：查账单、查订阅、转账（演示）、挂失（演示）。其余任务（异常交易、余额、卡状态、生日联动）收进「更多任务」折叠区。
2. **删除场景能力卡区**（与一键卡重复）；示例芯片减到 3 个。
3. **结果就地确认**：点卡片后，结果页在结论正下方直接显示本次任务的「确认/拒绝」大按钮（黄=确认执行，红=一键完成强验证），不再要求切到「待确认」标签页；确认后同位置显示回执。
4. **「待确认」标签页保留**，仅作为全部待办的总队列。
5. **文案瘦身**：每个面板的说明文字压到一行以内；删除"对齐赛题"等自我说明性标签；演示标注只保留一句话。
6. **导航保持现有顶部标签栏**（用户此前明确要求过），标签数量不增加。

## 约束
- 保留设计系统（深色画布、金橙渐变、玻璃卡片、侧栏、金 K 标识）。
- 真链路模式与公开演示模式行为一致（同一套交互）。
- 所有资金动作旁保留"演示模拟/公开演示数据"诚实标注。
- 不新增页面、不新增后端接口。

## 验收标准
- 从打开页面到看到账单结果：1 次点击。
- 从发起到确认转账：2 次点击，全程不切标签页。
- 每个可见按钮点击后 1 秒内有可感知变化。
- 桌面与移动端（390px）无横向溢出、无死按钮。
