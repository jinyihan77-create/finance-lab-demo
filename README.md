# Finance Lab 演示站

Fintechathon 2026 参赛作品的在线演示：<https://lixjanus526-art.github.io/finance-lab-demo/>

- 首页：橙色金属 K 变硬币、液体天平互动（手机与网页一致，两侧并排）、小硬币在两侧天平间抛接 4 个来回
- 个人投资顾问：持仓健康检查、三种方案对照
- 店主财务助手：账单来源核对、现金日历、晚到账试算

本仓库只存放静态构建结果，由团队私有仓库 `codex/kosx-landing-glass` 分支用 `npm run build:static` 生成，请勿直接修改这里的文件。
所有数据均为固定虚构演示数据；计算在浏览器内完成，不连接真实账户或交易，刷新页面会重置操作。

## 本地真链路改造版（2026-10-12 · qiqi）

本目录是上述静态站点的**本地改造副本**（D:\finance-lab-demo，不推回 GitHub Pages）。原始文件仍保存在 git 历史（HEAD de57a51）中，可随时回滚。

改造目标：保留原设计系统（深色画布、金橙品牌、玻璃卡片、侧栏工作台、流程条），把产品叙事从"双场景演示"升级为**银行 AI 智能体（安全任务执行台）+ 角色分支**：

- 新增 `workspace.html`：自然语言 → 任务 DAG → 绿黄红权限 → 人在环确认 → 可回放回执（账单/转账/卡片/订阅/理财/跨场景六场景，真链路）。
- `landing.html`：单一产品叙事 + 角色定位（个人用户 / 小店店主）。
- `investment.html`（理财旗舰）、`merchant.html`（小店经营助手·店主角色分支）、`catalog.html`：侧栏改为按角色分组导航，沿用演示数据并如实标注。
- `versions/api.js`：请求接缝——真链路优先（同源代理到团队后端），后端不可用或路由不在白名单时回退内置演示 harness；右下角徽标如实显示每页数据来源。
- `versions/console.css`、`versions/workspace.js`、`serve.py`、`启动演示.bat`：新增。

本地运行：

1. 先启动团队后端：在团队仓库运行 `python web/launch.py`（127.0.0.1:8765）。
2. 在本目录运行 `python serve.py --open`（或双击 `启动演示.bat`，站点在 http://127.0.0.1:8766/）。
3. serve.py 只把白名单 /api 路由转发到后端；其余接口回退页面内置演示数据。后端未启动时全站降级为演示模式并明确标注。

验收：黄金路径 14/14 通过（绿账单 → 黄转账+回执 → 红挂失强验证 → 连续失败熔断 → 人工恢复 → 注入拦截 → 跨场景联动）；桌面 1440 与移动 390 无横向溢出。

注意：本仓库原是静态构建结果（源在团队私有仓库 codex/kosx-landing-glass），如要并入主线，需把改动回迁源仓库，或按团队 web/static 方式由 web/app.py 同源服务。
